# Contributing to pichu

Thanks for helping improve pichu.

## Getting Started

1. Fork the repo and create a feature branch.
2. Set up the project locally:

```bash
make dev
```

3. Run checks before opening a PR:

```bash
make test
make lint
```

## Development Guidelines

- Keep changes focused and small.
- Follow the existing project structure and naming conventions.
- Add or update tests for behavior changes.
- Update docs when behavior or interfaces change.

## Pull Request Checklist

- [ ] Code builds and tests pass locally.
- [ ] New/changed behavior is covered by tests.
- [ ] Documentation is updated (if needed).
- [ ] PR description explains the problem and solution.

## Reporting Issues

Use the GitHub issue template and include:

- What happened
- What you expected
- Reproduction steps
- Environment details (OS, Python version, commit/tag)

## Code of Conduct

By participating, you agree to be respectful and constructive in all interactions.
